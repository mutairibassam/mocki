Mocki

Mocki is an automated load testing tool.
  • author: mutairibassam
  • contribution: mocki
  • features/bugs: mutairibassam@gmail.com
  • version: v0.1.1-beta

Appendix

  • Pipelining: The number of pipelined requests to use. default: 1. Note: backend pipelining support is required, otherwise will be defaulted to 1.
  • Connection: The number of concurrent connections to use. default: 10.
  • Max connection: The max number of requests to make per connection to the server.
  • Max Overall Requests: The max number of requests to make overall to the server.
  • Duration: The number of seconds to run the autocannon. default: 10.
  • Connection Rate: The max number of requests to make per second from an individual connection.
  • Overall Rate: The max number of requests to make per second from all connections.
